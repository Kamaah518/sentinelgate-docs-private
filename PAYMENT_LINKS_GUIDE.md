# Apple Pay

Accept payments from customers using Apple Pay on Safari, iOS apps, and macOS. Tokenized card-on-file transactions with biometric authentication (Face ID / Touch ID).

---

## Overview

| Field | Value |
|-------|-------|
| Rail Code | `APPLE_PAY` |
| Currency | USD, EUR, GBP, CAD, GHS, KES + 60 more |
| Settlement | Real-time authorization / T+1 settlement |
| Min Amount | $0.01 |
| Max Amount | No fixed limit |
| Availability | 24/7 |
| Supported Devices | iPhone, iPad, Mac (Safari), Apple Watch |

## How It Works

```
Customer → Taps "Pay with Apple Pay" → Face ID / Touch ID / Passcode
→ Device Generates Payment Token → Token Sent to SentinelGate
→ SentinelGate Decrypts & Charges → Callback → Order Confirmed
```

1. Merchant displays the Apple Pay button on checkout
2. Customer taps and authenticates with Face ID, Touch ID, or passcode
3. Apple generates an encrypted payment token (DPAN + cryptogram)
4. Token is sent to SentinelGate via `/v1/wallet/apple-pay/charge`
5. SentinelGate decrypts the token, extracts card network data, and processes the charge
6. Instant authorization; settlement follows standard card timelines

## Prerequisites

Before integrating Apple Pay you need:

1. **Apple Developer Account** — enroll at developer.apple.com
2. **Merchant ID** — create in Apple Developer → Certificates, Identifiers & Profiles
3. **Payment Processing Certificate** — generated by SentinelGate, uploaded to Apple
4. **Domain Verification** — verify your domain with Apple (SentinelGate hosts the verification file)
5. **HTTPS** — Apple Pay only works on HTTPS pages

## Integration

### Web (JavaScript — Apple Pay JS API)

#### 1. Check Availability & Create Session

```html
<!-- Add Apple Pay button -->
<div id="apple-pay-button-container"></div>

<script>
document.addEventListener('DOMContentLoaded', async () => {
  // Check if Apple Pay is available
  if (!window.ApplePaySession || !ApplePaySession.canMakePayments()) {
    console.log('Apple Pay not available on this device/browser');
    return;
  }

  const button = document.createElement('apple-pay-button');
  button.setAttribute('buttonstyle', 'black');
  button.setAttribute('type', 'buy');
  button.addEventListener('click', onApplePayClicked);
  document.getElementById('apple-pay-button-container').appendChild(button);
});

async function onApplePayClicked() {
  const paymentRequest = {
    countryCode: 'US',
    currencyCode: 'USD',
    supportedNetworks: ['visa', 'masterCard', 'amex'],
    merchantCapabilities: ['supports3DS'],
    total: {
      label: 'Your Store Name',
      type: 'final',
      amount: '49.99'
    }
  };

  const session = new ApplePaySession(14, paymentRequest);

  // Apple calls this to validate your merchant identity
  session.onvalidatemerchant = async (event) => {
    const response = await fetch('/api/apple-pay/session', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ validationURL: event.validationURL })
    });
    const merchantSession = await response.json();
    session.completeMerchantValidation(merchantSession);
  };

  // Apple calls this after customer authenticates
  session.onpaymentauthorized = async (event) => {
    const token = event.payment.token;

    // Send token to SentinelGate
    const result = await fetch('/api/apple-pay/charge', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        payment_token: token,
        amount: '49.99',
        currency: 'USD',
        order_id: 'ORD-001'
      })
    });

    const data = await result.json();

    if (data.ok && data.status === 'CAPTURED') {
      session.completePayment(ApplePaySession.STATUS_SUCCESS);
    } else {
      session.completePayment(ApplePaySession.STATUS_FAILURE);
    }
  };

  session.oncancel = () => console.log('Apple Pay cancelled by user');
  session.begin();
}
</script>
```

## Sample Code

### Node.js (Express — Full Server)

```javascript
const express = require('express');
const axios = require('axios');
require('dotenv').config();

const app = express();
app.use(express.json());
app.use(express.static('public'));

const sg = axios.create({
  baseURL: 'https://sentinelgate.biz',
  headers: { 'x-api-key': process.env.SG_API_KEY, 'Content-Type': 'application/json' }
});

// Step 1: Validate merchant session with Apple
app.post('/api/apple-pay/session', async (req, res) => {
  try {
    const response = await sg.post('/v1/wallet/apple-pay/session', {
      merchant_id: process.env.MERCHANT_ID,
      validation_url: req.body.validationURL,
      domain: 'yourstore.com',
      display_name: 'Your Store'
    });
    res.json(response.data.merchant_session);
  } catch (err) {
    console.error('Session validation failed:', err.response?.data);
    res.status(500).json({ error: 'Merchant validation failed' });
  }
});

// Step 2: Charge the Apple Pay token
app.post('/api/apple-pay/charge', async (req, res) => {
  try {
    const { payment_token, amount, currency, order_id } = req.body;
    const response = await sg.post('/v1/wallet/apple-pay/charge', {
      merchant_id: process.env.MERCHANT_ID,
      amount_cents: Math.round(parseFloat(amount) * 100),
      currency: currency || 'USD',
      email: 'customer@example.com',
      reference: `apple_${order_id}_${Date.now()}`,
      callback_url: 'https://yoursite.com/webhooks/apple-pay',
      payment_token
    });
    res.json(response.data);
  } catch (err) {
    console.error('Apple Pay charge failed:', err.response?.data);
    res.status(500).json({ ok: false, error: 'Charge failed' });
  }
});

// Webhook
app.post('/webhooks/apple-pay', (req, res) => {
  const { event, transaction_id, status } = req.body;
  console.log(`[APPLE_PAY] ${event} | ${transaction_id} | ${status}`);
  res.json({ received: true });
});

app.listen(3000, () => console.log('Apple Pay server on http://localhost:3000'));
```

### Python

```python
import requests, os, time

API = 'https://sentinelgate.biz'
HEADERS = {'x-api-key': os.environ['SG_API_KEY'], 'Content-Type': 'application/json'}

def validate_apple_session(validation_url):
    """Validate merchant session with Apple servers"""
    resp = requests.post(f'{API}/v1/wallet/apple-pay/session', json={
        'merchant_id': os.environ['MERCHANT_ID'],
        'validation_url': validation_url,
        'domain': 'yourstore.com',
        'display_name': 'Your Store'
    }, headers=HEADERS)
    return resp.json()['merchant_session']

def charge_apple_pay(payment_token, amount_cents, currency, email):
    """Charge an Apple Pay token"""
    resp = requests.post(f'{API}/v1/wallet/apple-pay/charge', json={
        'merchant_id': os.environ['MERCHANT_ID'],
        'amount_cents': amount_cents,
        'currency': currency,
        'email': email,
        'reference': f'apple_{int(time.time())}',
        'callback_url': 'https://yoursite.com/webhooks/apple-pay',
        'payment_token': payment_token
    }, headers=HEADERS)
    return resp.json()

# Flask endpoint example
from flask import Flask, request, jsonify
app = Flask(__name__)

@app.route('/api/apple-pay/session', methods=['POST'])
def apple_session():
    session = validate_apple_session(request.json['validationURL'])
    return jsonify(session)

@app.route('/api/apple-pay/charge', methods=['POST'])
def apple_charge():
    data = request.json
    result = charge_apple_pay(
        data['payment_token'],
        round(float(data['amount']) * 100),
        data.get('currency', 'USD'),
        data.get('email', 'customer@example.com')
    )
    return jsonify(result)
```

## Error Codes

| Code | Description |
|------|-------------|
| `DOMAIN_NOT_VERIFIED` | Your domain is not verified with Apple |
| `SESSION_VALIDATION_FAILED` | Merchant session validation failed |
| `TOKEN_DECRYPT_FAILED` | Could not decrypt the Apple Pay token |
| `TOKEN_EXPIRED` | Payment token has expired |
| `CARD_DECLINED` | Underlying card was declined |
| `UNSUPPORTED_NETWORK` | Card network not supported |
| `3DS_FAILED` | 3D Secure verification failed |
| `MERCHANT_NOT_CONFIGURED` | Apple Pay not configured for this merchant |
